# Social Media Post Review

Review page and coordinator portal for the Social Media Team, Department of EM, IIT Hyderabad.

This site only contains page layout and code. **No posts, photos, names or email addresses are stored here.**
Everything is loaded from the department's Google Apps Script using the personal code in each link
(the part after `#`, which browsers never send to this website).

- `index.html`: review page for approvers (`…/#t=<personal code>`)
- `coordinator.html`: coordinator portal (`…/coordinator.html#c=<coordinator code>`)
- `config.js`: address of the Apps Script web app
